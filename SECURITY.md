# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Bug Whisper, please report it privately rather than opening a public issue.

1. Email the maintainers directly with details of the vulnerability.
2. Provide a proof of concept or reproduction steps.
3. Allow up to 48 hours for an initial response.

We will coordinate a patch and release an advisory once the vulnerability is addressed.
